# PetCare API (TypeScript)

Scaffold inicial da API em Node + TypeScript.

Comandos úteis:

```bash
cd Api
npm install
npm run dev   # modo desenvolvimento (ts-node-dev)
npm run build # compila para dist
npm start     # executa dist/index.js
```

Endpoints iniciais:
- `GET /health` -> status
- `GET /api/clients` -> lista de exemplo
