# PetCare

Projeto acadêmico: PetCare (Universidade de Passo Fundo - UPF)

Autores: Gustavo Gasparin Grando
Data: 2026

Resumo: Aplicativo mobile para gerir serviços pet (clientes, profissionais, serviços, agendamentos).

Arquivos criados:
- Api/ -> Node + TypeScript scaffold
- App/ -> Flutter scaffold

Referência do Documento de Visão do Produto (DVP): fornecido pelo usuário (DVP completo em HTML).

Próximos passos: instalar dependências em `Api/` e `App/`, inicializar repositório Git e fazer commit inicial.

Comandos sugeridos:

```bash
# Backend
cd Api
npm install
npm run dev

# Frontend
cd App
flutter pub get
flutter run
```
